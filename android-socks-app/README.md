# SockStore (Android Studio)

Aplicación móvil de ejemplo para compra de calcetines desarrollada con **Kotlin + Jetpack Compose**.

## Funcionalidades
- Catálogo de calcetines con nombre, material y precio.
- Control de cantidad por producto (`+` / `-`).
- Cálculo automático del total en tiempo real.
- Botón de checkout listo para conectar con pago real.

## Abrir en Android Studio
1. Abre Android Studio.
2. Selecciona **Open** y elige la carpeta `android-socks-app`.
3. Espera a que sincronice Gradle.
4. Ejecuta en un emulador o dispositivo físico.

## Requisitos sugeridos
- Android Studio Jellyfish o superior.
- JDK 17.
- SDK Android 34.
